# Spotify Web Player - UI Clone 🎧

A responsive and visually accurate clone of the Spotify Web Player user interface. This project was developed from scratch to practice advanced layout styling, alignment, and modern responsive web design techniques.

## 🚀 Live Demo
👉 **https://github.io**

## ✨ Key Features
- **Pixel-Perfect UI:** Recreated the exact dark-themed layout of Spotify, including the sidebar, navigation headers, and footer controls.
- **Advanced Layouts:** Implemented a combination of **CSS Flexbox** for the music control bar and **CSS Grid** for the song card layouts.
- **Fully Responsive Design:** Utilized CSS **Media Queries** to ensure the interface looks great on mobile, tablet, and desktop screens.
- **Hover Animations:** Added smooth CSS transitions and scale effects on album art and play buttons for a native app feel.

## 🛠️ Tech Stack Used
- **HTML5:** Semantic structuring of web components.
- **CSS3:** Custom layouts, positioning, properties, and theme matching.
